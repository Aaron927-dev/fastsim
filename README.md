# fastsim —— 自研快速仿真内核

**定位**：用「降维 + 解析 + 解析 Jacobian」替代 COMSOL 全 3D FEM 的参数扫描，
把单次求解从分钟级压到毫秒级，换取**设计寻优与趋势探索**的可行性。

**目标精度与速度**：在已对标的基准上距**解析解** ~0.01–0.1%，求解速度比 COMSOL
快 **2 个数量级** —— 定位是"低成本、超快速的自主仿真前端"，**不声称替代 COMSOL**。
COMSOL 保留为「独立实现的交叉校验器」与「复杂几何一次性建模」。

> **关于「达到 COMSOL 90% 精度」这个说法**：实测表明 COMSOL 自身在最平凡的
> 平行板问题上也带 0.3–0.9% 数值误差（网格收敛扫描，二阶），耦合电流分布上约 2%
> —— **COMSOL 不是精确参照物**。因此本项目的判据是**对解析解 / 对实验**，
> COMSOL 只作独立实现的交叉检查。详见下文「COMSOL 交叉验证」。

**安装**（仅需 numpy + scipy）：

```bash
pip install -e .                     # 仅核心库
pip install -e ".[bench]"            # 额外装 mph（驱动 COMSOL，需本机已装 COMSOL）
pip install -e ".[dev]"              # 额外装 pytest
```

## 为什么做这个

传统 COMSOL 工作流的四个痛点（也是本项目的立项理由）：

| 痛点 | 具体表现 |
|---|---|
| **算力** | 全 3D FEM 网格动辄百万自由度，单算例分钟到小时级 |
| **周期** | 改一个参数要重建模型、重新剖网格、重新求解 |
| **验证慢** | 一个参数扫描跑一天，设计迭代被算力锁死 |
| **脚本化摩擦** | 程序化驱动 COMSOL 是「黑箱 + 静默失败」，API 属性名试错成本极高（见 `docs/COMSOL脚本化踩坑记录.md`） |

**核心思路**：环境电化学反应器是**规则几何**（环隙 / 圆管）+ **中等 Re** +
**稀溶液**，大量物理可用解析式与关联式替代数值求解。

## 四基座状态

| 基座（对应 COMSOL 模块） | 状态 | 已实现 |
|---|---|---|
| **① 电化学**（Electrochemistry） | ✅ | 环隙一/二次电流分布、Butler-Volmer、**固相欧姆降**、恒流/恒压求解；电极特性（j₀/α/E_eq/G）与水质特性（κ）全参数化 |

| **③ 流场**（CFD） | ✅ | 环隙/圆管层流解析剖面、Re 流态判据、Graetz/Dittus-Boelter 传质、Taylor-Aris 弥散（均带适用域守卫） |

| **⑤ 优化**（Optimization） | ✅ | 灵敏度分析、**参数估计**（含不确定度与可辨识性诊断）、**贝叶斯寻优**（GP + EI） |

**四基座全部建成并互相打通** —— 电场 → 界面 → 化学场是一条闭环链路，

## 核心示例

**① 电-化耦合闭环**（`demo_eco_reactor.py`）

```
① 电场        SecondaryCurrent2D → 局部电流密度 j(z)
② 界面        法拉第定律 → O₃ 生成通量 = j·CE/(nF)
③ 降阶        完整臭氧链（0D 机理库）→ Rct → 二级动力学 k₂
④ 化学场      ADR2D → 环隙流动 + 反应-传质
⑤ 评价        降解率、比能耗 E_EO
```

第 ③ 步的意义：完整臭氧链速率常数跨度 1e-3 ~ 1e10，直接进二维场会极端刚性。
用 QSSA 消去自由基（`d[S]/dt = −k_{·OH,S}·Rct·[O₃]·[S]`），
而 **Rct 由完整机理库独立算出** —— 降阶模型与完整机理同源，不是拍参数。

**② 设计寻优**（`demo_design_optimization.py`）

以完整耦合仿真为目标函数，寻优电流与流量使比能耗最小。
**BO 找到 E_EO = 0.0558，同等预算随机搜索均值 0.5939（优 90.6%）**。

## 数值格式：借鉴成熟开源实现

对流项的处理**参考 NIST 的 FiPy**（[usnistgov/fipy](https://github.com/usnistgov/fipy)）
与 Patankar《Numerical Heat Transfer and Fluid Flow》的 **A(|P|) 统一框架**。
面上净通量写成：

```
F = D·A(|P|)·(φ_P − φ_A) + max(F_c,0)·φ_P + min(F_c,0)·φ_A
```

取不同的 A(|P|) 即得不同格式：

| 格式 | A(\|P\|) | 收敛阶（实测 MMS） | 有界 |
|---|---|---|---|
| 一阶迎风 | 1 | 1.00 | ✅ |
| **幂律（本项目默认，同 FiPy）** | max(0, 1−0.1\|P\|)⁵ | **1.84** | ✅ |
| 指数 | \|P\|/(e^\|P\|−1) | 1.92 | ✅ |
| 混合 | max(0, 1−0.5\|P\|) | 1.91 | ✅ |
| 中心差分 | 1 − 0.5\|P\| | 1.91 | ❌ 高 Pe 振荡 |

**为什么选幂律作默认**：它无条件满足正系数条件（稳态有界、无伪振荡），
同时在对流主导区比迎风**少得多的数值扩散**。实测在最细网格上误差
比迎风低 **5.2 倍**（2.99e-4 vs 1.56e-3），收敛阶从 1.00 提到 1.84。
这与 FiPy 的选择一致。

复现证据：`python bench/mms_convergence.py`

- 几何（论文原文）：电极宽 20 mm × 通道高 1.5 mm，充分发展层流

| 判据 | 论文 | 本求解器 | 偏差 |
|---|---|---|---|

| 流量标度律 c(0) ∝ Q^n<br>（与未知参数无关，最强判据） | n ≈ −0.364 | n = −0.351 | 0.014 |

## COMSOL 交叉验证（自建基准）

用 COMSOL **自带的应用库模型**做基准（`COMSOL_Multiphysics/Chemical_Engineering/
transport_and_adsorption.mph`，改造为纯对流-扩散-反应），构成三方对标：

| 对象 | 距解析解 | 说明 |
|---|---|---|
| **fastsim（1600 单元）** | **0.0004%** | 收敛阶 1.92 |
| COMSOL（590 节点自动网格） | 0.98% | 流向有效分辨率仅约 20 格 |
| 两者互差 | 2.13% | — |

出口浓度：COMSOL 0.3928 / fastsim 0.3715 / 解析解 0.3715（fastsim 偏差 0.0016%）。

**「COMSOL 偏差来自分辨率」已证实**（`bench/resolution_check.py`）：
把 fastsim 降到 20 个流向单元时误差 0.9246% —— 正是 COMSOL 的 0.98%。
即 590 个节点分布在二维域上后，流向有效分辨率只有约 20 格，
**偏差是分辨率造成的，不是物理模型差异**。

**诚实表述**：fastsim 在本问题上比 COMSOL 默认网格更接近解析解，
**不是**因为算法更强，而是因为**自研求解器快，可以用更细的网格**。
这正是"快速求解"的实际价值：同样的时间预算下能买到更高的分辨率。

复现：`python bench/cross_validate.py && python bench/resolution_check.py`

### 多物理耦合基准：电化学电流分布（SCD）

此前文档把「电化学耦合场景的 COMSOL 交叉验证」列为**未解决缺口**。现已打通。
根因是**边界编号假设错误**（详见
[`docs/COMSOL脚本化踩坑记录.md`](docs/COMSOL脚本化踩坑记录.md) 第六节）：
`Rectangle(pos=[0,0], size=[gap,L])` 的真实编号是
**1=x=0/r=r_inner、2=y=0/z=0、3=y=L/z=L、4=x=gap/r=r_outer** ——
与「1=底 2=右 3=顶 4=左」相比 **1 与 2 互换**；电极边是 **1 与 4**。

**三方同题比对**（`bench/threeway_annulus.py`，环隙 r_i=5 mm / r_o=10 mm / L=0.2 m，
κ=1 S/m，目标为一维解析解 —— 含欧姆降 + Butler-Volmer，标量求根，无自由参数）：

| 算例 | 解析解 | COMSOL | COMSOL 偏差 | **fastsim** | **fastsim 偏差** |
|---|---|---|---|---|---|
| 环隙一次分布 | I′=18.129441 A/m | 18.164839 | +0.20% | 18.127845 | **−0.01%** |
| 环隙二次分布（i0=1e−3） | I′=6.982952 A/m | 7.117602 | +1.93% | 6.982409 | **−0.01%** |

笛卡尔平行板（`bench/comsol_scd_benchmark.py`）另测三个 i0：
COMSOL 电流密度偏差 3.08% / 2.34% / 2.84%，剖面线性、轴向跨度 3–6e−4 V。

**耗时（诚实口径）**：fastsim **49.5 ms**（3840 未知量，20 次均值）
vs COMSOL **6.842 s**（仅 `sol1.runAll()`，**不含**约 25–35 s 的启动与建模）→ **≈138×**。
且 fastsim 精度更高，即**用更少未知量买到更高精度**。

**由此暴露并修复了 fastsim 的一个真实缺陷**（第 17 个，见下节）：
二次分布分支用首个单元**中心**的 φ_l 计算过电位，而动力学作用在**电极表面**，
两者相差半个单元的欧姆降 (Δr/2)·j/κ —— 引入 **一阶**空间误差。
修复后 n_r=32 时偏差从 **+3.07% 降到 −0.008%**，
且实测偏差与闭式预测在 n_r=8…256 全范围逐行吻合
（`bench/fastsim_radial_convergence.py`）。127 项测试全部通过。

**COMSOL 自身误差是分辨率限制的**（笛卡尔平行板网格收敛扫描）：

| 每 gap 单元数 | RMS vs 解析 | y 向跨度（应=0） |
|---|---|---|
| 16 | 1.851e−2 | 1.271e−3 |
| 32 | 1.775e−2 | 7.580e−4 |
| 64 | 6.480e−3 | 3.279e−4 |

二阶收敛。**即在最平凡的平行板问题上 COMSOL 自身也带 0.3–0.9% 误差 ——
COMSOL 不是精确参照物**，这标定了「达到 COMSOL 90% 精度」这个目标的天花板。

⚠ 注意：COMSOL 脚本化踩过的坑已汇总在
[`docs/COMSOL脚本化踩坑记录.md`](docs/COMSOL脚本化踩坑记录.md)，
其中 **`feature().create(tag, type, edim)` 的第三参数是「单元维度」**

## 优化基座怎么用

```python
from fastsim.optim import sensitivities, fit, bayesian_optimize

# 1) 灵敏度：哪个参数最要紧（归一化 = 弹性系数，可跨量纲比较）
res = sensitivities(objective, x0=[0.2, 10.0], names=["电流 A", "流量 mL/s"])
print(res.table())          # 带条形图的排序表

# 2) 参数估计：用实验数据反推，并拿到不确定度与可辨识性诊断
fitres = fit(model, theta0, t_data, y_data, names=["k1", "k2"], sigma=0.02)
print(fitres.report())      # 含 95% 区间、相关系数矩阵、条件数

# 3) 设计寻优：少量高保真调用找到最优点
opt = bayesian_optimize(objective, [(0.02, 0.5), (2.0, 60.0)],
                        n_init=8, n_iter=20, names=["电流", "流量"])
print(opt.report())
```

## ⚠️ 三个必须知道的约定

**1. 浓度单位是 SI 的 mol/m³**
守恒式要求「浓度 × 体积流量 = 摩尔流量」，而壁面通量是 mol·m⁻²·s⁻¹。
只有浓度取 mol/m³ 时 `mol/m³ × m³/s = mol/s` 才与 `mol/m²/s × m² = mol/s` 同量纲。
**文献速率常数是 M 基**，二级常数必须换算：`k[mol/m³基] = k[M基] / 1000`
（用 `mechanisms.k_second_order_to_SI`）。忘记这步会让反应速率差 **1000 倍**。

**2. 速度场必须满足 ∇·u = 0**
求解器用守恒形式 ∇·(u·c)，非无散速度场会凭空多出源项 `c·∇·u`。
用 `ADR2D.divergence_free_violation()` 自检（应 < 1e-6）。

**3. 目标函数的入参契约**
`bayesian_optimize` 传给目标函数的是**一维数组**（单设计点，形状 `(d,)`），
不是批量矩阵。若你的目标函数是向量化的，需自行包装：
`lambda x: vec_func(x[None, :])[0]`。

## 反应网络层与化学体系无关

框架不内置任何机理：ECO（电催化臭氧化）、芬顿、或任何体系各自构造
`ReactionNetwork` 即可，互不通用。AOP 机理库（`mechanisms.py`）是**可选预置**，
带假设清单与速率常数出处，便于追溯。

## 开发中自查出的缺陷（全部由「跑真实示例」暴露，测试没抓到）

1. **绝对容差导致静默返回初值** —— 小通量工况下初始残差本就小于容差，牛顿第一步就"收敛"
2. **守恒形式与非无散速度场不自洽** —— 误差 45% 且随网格加密**上升**（离散收敛到另一个问题）
3. **壁面通量的静默广播** —— 产物也被"消耗"而变负；改为显式报错
4. **内外壁面通量符号相反** —— 面法线方向不同，沿用外侧符号导致物质被"吸走"
5. **收敛判据单尺度失效** —— 只用物理尺度在高活性电极下过严；只用初始残差在热启动下过严；最终取两者较宽松者
6. **单位一致性** —— 浓度必须是 mol/m³ 才能与法拉第通量同量纲；二级 k 需 ÷1000
7. **污染物直接氧化不能用固定通量** —— 受传质控制，给定通量比极限高 5 个数量级会拉出负浓度
8. **Jacobian 逐单元 Python 循环** —— 单次装配 0.1 s，Newton 上百次迭代累计到 78 s；向量化 + 热启动后降到 261 ms（端到端）
9. **EI 采集函数双重取负** —— 最小化被反向当最大化求解，**BO 全面劣于随机搜索**；
   用标准基准 Branin 才发现（症状很容易被误判成"景观太难"）
10. **GP 超参数塌缩** —— 噪声设 1e-10 使边缘似然被"ℓ→0 完美插值"支配，测试 R² 变**负**
11. **GP 输入未归一化** —— 各维量纲不同时长度尺度不可比（同一问题两方向差 3 万倍）
12. **条件数门槛设成固定大数** —— 未考虑两参数时 `cond≈(1+|r|)/(1−|r|)`，会漏报 r=0.90 级病态
13. **残差尺度用入口浓度定标** —— 对「入口浓度为零、原位生成」的物种
    （电极生成 H₂O₂/O₃，AOP 的典型场景）c_ref 塌缩到 1e-30，
    解已正确收敛却报「未收敛」并触发稠密回退
14. **跨函数边界的参数语义不同步** —— `_damped_newton` 的第三参数从「绝对阈值」
    改成「相对容差」后调用处未同步，牛顿空转满 80 次迭代（含线搜索）：
    实测 7200 未知量的**线性**问题耗时 **231 s**（本该一步收敛），修复后 **0.01 s**
15. **稠密回退无规模守卫** —— `hybr` 会构造 (N·ns)² 稠密 Jacobian，
    16 万未知量需 191 GB → 内存溢出；已加规模上限并改为显式报告
16. **电极过电位漏掉半个单元** —— 二次分布分支用首个单元**中心**的 φ_l 算过电位，
    而动力学作用在**电极表面**，两者相差 (Δr/2)·j/κ。这是 **一阶**空间误差：
    实测 n_r=32 时电流偏高 **+3.07%**，且随 n_r 以 O(Δr) 收敛（不是 O(Δr²)）。
    同文件的一次分布分支其实**已经**用半单元电导 `κA/(Δr/2)` 体现了这段电阻 ——
    两个分支不一致本身就是线索。修复（把 φ_l 外推到电极表面，隐式求解 + 对
    隐式关系求导修正 Jacobian）后 n_r=32 偏差 **−0.008%**，
    且实测与闭式预测在 n_r=8…256 全范围逐行吻合。
    **发现方式：与 COMSOL 三方比对时两者同向偏高 2–3%，提示是离散而非模型问题。**

## 已知限制（诚实声明）

- **未做**：3D 湍流、自由界面、多相流细节、形状/拓扑优化 —— 这些仍需 COMSOL
- **COMSOL 对标覆盖度（诚实说明）**：
  - ✅ **已对标**：单物理的对流-扩散-反应（`bench/cross_validate.py`，
    fastsim vs 解析解 0.0004%，COMSOL 0.98%，已证实差异源于分辨率）
  - ✅ **已对标**：**电化学耦合**（电场 + Butler-Volmer 电极动力学）——
    环隙一次/二次电流分布的三方同题比对（`bench/threeway_annulus.py`）：
    fastsim 距解析解 **−0.01%**，COMSOL +0.20% / +1.93%。
    此前记录的「卡在 SCD 边界语义上」是**误判**，真因是边界编号假设错误；
    另「默认 Insulation 会压过 ElectricPotential 使解恒为 0」也不成立，
    该现象实际来自邻边电极（见 `docs/COMSOL脚本化踩坑记录.md` 第六节更正）。
  - ⚠️ **未完成**：**三者同时耦合**（电场 + 化学反应 + 流动同一个模型）的 COMSOL 对标。
    现有覆盖是「电场+动力学」已交叉验证、「化学+流动」已交叉验证，但
    三者放进同一个 COMSOL 模型跑一次的验证尚未做。
  - **关于「90% 于 COMSOL」这个目标**：实测表明 COMSOL 自身在最平凡的平行板上
    也带 0.3–0.9% 数值误差（网格收敛扫描，二阶），在耦合 SCD 上约 2%。
    因此「达到 COMSOL 90%」是个**偏松**的靶子；在上述基准上 fastsim
    实际比 COMSOL 更接近解析解。真正有意义的判据是**对解析解/对实验**，
    COMSOL 只作为独立实现的交叉检查。
- **未做**：Robin 型壁面边界（通量 = k_L·c）—— 直接阳极氧化受传质控制，
  当前固定通量接口不足以正确表达，故示例走间接氧化路径
- **未做**：多孔电极体积平均方程（σ_eff / κ_eff / 比表面积）
- **未做**：EIS、瞬态电位扫描/CV
- **GP 已知边界**：峰宽 σ ≲ 0.1 的极窄极值会被平方指数核平滑掉，
  此时贝叶斯寻优优势消失（实测胜率降至 50%）；需要 Matérn 核或更大初采
- 关联式与解析解外推有适用域限制，**超域时报错而非外推**
